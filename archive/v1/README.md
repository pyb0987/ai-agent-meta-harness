# AI Agent Meta-Harness v1 Archive

This archive freezes the repository governance model that existed before the
v2 transition.

v1 used human-authored maintenance records:

- Start Gate and Completion Gate records.
- Multi-review and isolated reviewer summaries.
- Search-set before/after evidence written into backlog records.
- Score, VETO, rerun, score-9, residual-risk, and archive lifecycle fields.
- Repository checks that validated those document records.

The v1 material is no longer the active roadmap. It remains evidence for why the
v2 packet-based governance model exists: the repository repeatedly needed more
rules to keep agents from weakening scope, review, evidence, or archive
discipline.
